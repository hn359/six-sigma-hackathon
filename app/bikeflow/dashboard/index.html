What is unusual at each station, and which bikes should move. Press play to watch the day unfold reading by reading.

01 · Station status

Which stations need attention right now?

Each bar is one station: how full it is right now. The green zone is the healthy range (not too empty, not too full). The black tick is where the station should be at this time on a normal day.

02 · Today at each station

How each station's day is going

Solid line = bikes at the station so far today. Dashed line = a normal day. Green band = healthy range. Red dot = something unusual happened (hover to see what). ▲ / ▼ = the van dropped off / picked up bikes.

03 · Rider flow

Where are riders going?

Each box counts the trips from one station (row) to another (column). The darker the box, the more riders made that trip. Totals: how many rides left each station, and how many arrived at each.

    06 · Control chart

    Is the station behaving like a normal day? (I-MR chart, eight tests)

    Each point is the station's rider net flow in one reading minus what is usual at that time of day (learned from week 1, when no van ran). Around the centre line, Zone C is within 1σ, Zone B 1–2σ and Zone A 2–3σ; the dashed red lines are the 3σ control limits (course lesson 5: σ = MR̄ / 1.128, MR UCL = 3.267 MR̄). A point that completes one of the eight tests gets that test's symbol and is labelled with every test it fired. Station: (change it with "Control-chart station" at the top).
